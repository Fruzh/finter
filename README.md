# Finter - Personal Finance Management Platform

Finter is a comprehensive personal finance tracking and asset management platform designed to provide users with complete control over their financial health. The platform is structured around segregated asset management, detailed transaction logging, and intelligent automation.

## Core Features

### 1. Interactive Financial Dashboard
* **Dynamic KPIs**: Instant oversight of total assets, net income, overall expenses, and current cash balances.
* **Monthly Financial Trends**: Visual analytical charts displaying income versus expenditure progressions over time.
* **Saving Rate Tracker**: Real-time progress monitoring to ensure savings objectives are consistently met.

### 2. Segmented Asset Allocation
* **Cashflow Wallets**: Daily transaction accounts designed for managing fluid cash, bank balances, and e-wallets.
* **Saving Goals**: Dedicated vaults for long-term saving goals and passive asset tracking.
* **Investment Portfolios**: High-fidelity tracking of capital holdings, stock/crypto trading history, and real-time Profit and Loss (PnL) analysis.

### 3. Advanced Transaction Management
* **Income & Expense Ledgers**: Granular transaction history with flexible date logging, custom notes, and multi-currency formatting (IDR and USD).
* **Fund Transfers**: Secure bookkeeping for moving funds between accounts, including support for fixed or percentage-based transaction fees.

### 4. Custom Configuration Center
* **Account Management**: Ability to add, modify, or deactivate fluid wallets, savings vaults, and investment accounts.
* **Dynamic Categorization**: Fully customizable systems for defining income sources, income types, expense categories, and subcategories.

### 5. Finter AI Intelligent Assistant
* **Natural Language Logging**: Register incomes, expenses, and transfers instantly by conversing with the integrated chatbot in plain text.
* **Autonomous Option Creation**: Automatically add new categories or income sources on-the-fly during conversation.
* **Contextual Page Redirection**: Seamless navigation that automatically guides the user to the relevant financial page upon transaction registration.
* **Real-time Synchronization**: Instant data updates across all pages as soon as the assistant completes an action.
